# Лабораторная работа 4. Алгоритмический мини-пакет

## Результат

Устанавливаемый пакет с алгоритмами, структурой данных, генераторами тестовых наборов и benchmark.

## Рекуррентная задача

Реализовать итеративно и рекурсивно один вариант:

- Fibonacci;
- число способов подъёма по лестнице;
- наибольший общий делитель;
- быстрая степень;
- обход вложенной структуры.

Для рекурсивной функции обработать недопустимый ввод. В README указать ограничение рекурсии Python.

## Сортировки

Реализовать:

- одну квадратичную сортировку: bubble, insertion или selection;
- одну эффективную сортировку: merge, quick или heap.

Требования:

- запрещены `list.sort` и `sorted` внутри реализации;
- входной список не изменяется, если функция документирована как возвращающая новый;
- пустой список и дубликаты поддерживаются;
- отрицательные числа поддерживаются;
- поведение при неверном типе документировано.

## Структура данных

Реализовать один вариант:

- stack;
- queue;
- priority queue.

Обязательные операции: добавление, извлечение, просмотр следующего элемента, `len`, `bool`. Операция над пустой структурой вызывает документированное исключение.

## Генераторы наборов

- случайный;
- отсортированный;
- обратный;
- почти отсортированный;
- с большим количеством дубликатов.

Поддержать `seed` для воспроизводимости.

## Benchmark

- Использовать не менее 5 повторов.
- Сравнить размеры не менее 100, 1 000 и 10 000, если выполнение укладывается в разумное время.
- Не включать генерацию входа в измеряемое время.
- Для каждого запуска использовать независимую копию входа.
- Сформировать CSV или Markdown-таблицу.
- Сопоставить результат с ожидаемой сложностью.

## Тесты

- Пустой вход.
- Один элемент.
- Уже отсортированный и обратный вход.
- Дубликаты.
- Отрицательные числа.
- Воспроизводимость генератора.
- Ошибка пустой структуры данных.
