## Реализованные алгоритмы

### 1. Сортировки

В проекте реализованы две сортировки:

**Insertion Sort (сортировка вставками)**

Сортировка постепенно обрабатывает элементы массива и вставляет каждый элемент на подходящее место.

- Средняя и худшая сложность: O(n²).
- Лучшая сложность: O(n).
- Дополнительная память: O(n), так как создаётся копия исходного списка.

**Quick Sort (быстрая сортировка)**

Алгоритм выбирает опорный элемент и разделяет массив на части: меньше опорного элемента, равные ему и больше него. Затем части сортируются рекурсивно.

- Средняя сложность: O(n log n).
- Худшая сложность: O(n²).
- Дополнительная память: O(n log n) в среднем, без учёта особенностей максимальной глубины рекурсии.

Обе функции возвращают новый отсортированный список и не изменяют исходный массив.

### 2. Быстрое возведение в степень

Реализовано двоичное возведение в степень двумя способами:

- итеративным;
- рекурсивным.

Алгоритм использует последовательное возведение основания в квадрат и деление показателя степени на два.

- Временная сложность: O(log n).
- Дополнительная память: O(1) для итеративного варианта и O(log n) для рекурсивного.

Поддерживаются положительные, отрицательные и нулевые показатели степени.

### 3. Приоритетная очередь

Реализована приоритетная очередь на основе двоичной кучи.

Двоичная куча позволяет эффективно добавлять элементы и извлекать элемент с наивысшим приоритетом.

Основные операции:
- добавление элемента;
- извлечение элемента;
- просмотр следующего элемента;
- получение количества элементов;
- проверка, пуста ли очередь.

Сложность основных операций:
- добавление: O(log n);
- извлечение: O(log n);
- просмотр следующего элемента: O(1).

### 4. Генераторы данных

Реализованы пять генераторов массивов:

- Random — случайный массив;
- Sorted — отсортированный массив;
- Reverse — массив в обратном порядке;
- Nearly sorted — почти отсортированный массив;
- Duplicates — массив с большим количеством повторяющихся значений.

Генераторы поддерживают параметр `seed`, который позволяет получать одинаковые массивы при повторном запуске с одним значением.

## Benchmark

Для сравнения сортировок используется отдельный модуль `benchmark.py`.

В эксперименте участвуют:
- Insertion Sort;
- Quick Sort.

Используются следующие размеры массивов:
- 100 элементов;
- 1 000 элементов;
- 10 000 элементов.

Для каждого типа входных данных выполняется 5 повторов.

При измерении времени:
- генерация массива выполняется до начала измерения;
- для каждого запуска создаётся отдельная копия исходного массива;
- время измеряется с помощью `time.perf_counter()`;
- рассчитываются среднее и медианное время выполнения.

Результаты сохраняются в файл `benchmark_results.csv`.

### Анализ результатов

Результаты Benchmark позволяют сравнить практическое время работы алгоритмов с ожидаемой временной сложностью.

Insertion Sort показывает хорошие результаты на отсортированных массивах, но значительно медленнее работает на случайных и обратных данных.

Quick Sort обычно быстрее на больших массивах благодаря средней сложности O(n log n).

Небольшие отличия от теоретических оценок могут быть связаны с особенностями Python, компьютера и фоновой нагрузкой.

## Тестирование

Для автоматического тестирования используется библиотека pytest.

Тесты находятся в файле `tests/test_algorithms.py`.

Проверяются:
- пустые массивы и массивы из одного элемента;
- отсортированные и обратные массивы;
- дубликаты и отрицательные числа;
- сохранение исходного массива после сортировки;
- работа итеративного и рекурсивного возведения в степень;
- работа генераторов и воспроизводимость результатов через seed;
- основные операции приоритетной очереди;
- поведение при обращении к пустой очереди;
- основные настройки Benchmark.

## Установка и запуск

Рекомендуется использовать виртуальное окружение.

Установка pytest:

```bash
pip install pytest
```

Установка проекта:

```bash
pip install -e .
```

Запуск тестов:

```bash
python -m pytest tests/test_algorithms.py -v
```

Запуск Benchmark:

```bash
python -m algorithms.benchmark
```

После выполнения Benchmark файл `benchmark_results.csv` будет содержать результаты измерений.

## Ограничение рекурсии

Рекурсивные функции используют стек вызовов Python. Поэтому при слишком большой глубине рекурсии может возникнуть ошибка `RecursionError`.

Для больших входных данных итеративные алгоритмы обычно подходят лучше.
