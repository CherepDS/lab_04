## Обязательные проверки

- Обе сортировки совпадают с эталонным результатом на случайных массивах.
- Поддерживаются пустой список, один элемент, дубликаты и отрицательные числа.
- Поведение исходного списка соответствует документации.
- Эффективная сортировка не деградирует из-за очевидной ошибки на базовом тестовом наборе.
- Операция над пустой структурой вызывает заявленное исключение.
- Две генерации с одним seed совпадают.
- Две генерации с разными seed обычно различаются.
- Benchmark не измеряет создание массива.
- В README указана сложность времени и дополнительной памяти.
